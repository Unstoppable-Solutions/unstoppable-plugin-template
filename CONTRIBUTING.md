# Contributing

Thanks for your interest. This plugin lives on GitHub for development and on
WordPress.org for distribution. Issues, pull requests and discussions all
happen here on GitHub.

## Reporting bugs

Open an issue with:

- WordPress version
- PHP version
- Plugin version
- Steps to reproduce
- Expected vs. actual behavior

## Pull requests

- Branch from `main`, submit a PR back to `main`.
- The Plugin Check workflow runs on every PR and must pass.
- Match the existing code style — four-space tabs for PHP, PSR-12-adjacent for
  general structure, inline documentation on every function and class.
- Prefix all new classes, functions and constants with this plugin's assigned
  4+ character prefix.

## Security

Please report security issues privately rather than opening a public issue.
See `SECURITY.md` if present.
